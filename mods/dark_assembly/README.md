# Dark Assembly - Aprovação garantida

Este mod mantém todas as propostas aprovadas enquanto estiver ativado. A decisão
é alterada somente na memória da votação atual.

O arquivo `data/database/wish.dat` não é modificado. Ao desativar o mod, as
votações seguintes voltam a usar o resultado normal do jogo.

O plugin aceita apenas a versão do executável que foi verificada. Se a rotina de
votação não corresponder, o carregamento falha e nenhuma memória é alterada.
